# Изменения

## 0.1.0 - не выпущена

Первая оболочка.

- Вкладка «Игры» с карточками (превью, описание, версия, поиск); сломанная игра - с причиной.
- Общая статистика: партии, победы и лучшая серия каждой игры из её stats.json, итог по всем играм.
- Игра открывается во вкладке через `create_widget(ctx)`; общие тема, язык RU/EN, громкость,
  место окна.
- Скрытая вкладка - пауза (`pause/resume` игры или остановка её таймеров), закрытая -
  `shutdown()` за 2 секунды и удаление виджета.
- Игры копиями в `games/`: `tools/vendor_game.py` с переписыванием импортов. Дурак 1.0.0 (свои
  pause/resume) и Крестики-нолики 1.0.1 (через переходник).
- `tools/contract_check.py` - проверка папки игры по контракту, с запуском виджета без экрана.
- Сборка `build.py`: одна папка, portable-архив и установщик NSIS на все игры; значок нарисован
  кодом; самопроверка собранного exe.
- Тесты без экрана, мутационная проверка `tools/mutate.py`, CI на Gitea и GitHub.
- aikit 0.2.0: графики статистики для всех игр (`aikit.charts`, правило автора 10.10) - линия,
  столбики, сетка карточек в две колонки (в одну на узкой странице) и готовый набор `GameCharts`:
  доля побед, итоги по уровням ИИ, длина партии, рекорды, кривая обучения, паспорт силы ИИ. Журнал
  партий `aikit.gamelog`. Без данных - заглушка словами (одна точка - тоже заглушка, не пустая сетка),
  не влезшие подписи собираются в `chart.clipped`. `contract_check`: статистика без графиков -
  ошибка `stats.charts`, свои графики вместо общих - предупреждение.
