# Контракт игры

Каждая игра с ИИ, пока она живёт в своей папке, соблюдает эти правила. Тогда перенос в PythonAiGames сводится к копированию папки.

## Устройство папки

```
<Игра>/
  main.py              python main.py — запуск отдельно; --selftest <файл>; --offscreen
  aikit/               копия общего набора (см. ниже), НЕ править под игру — улучшения
                       переносятся во все копии и в PythonAiGames/aikit
  game/                ВСЁ своё здесь (при переносе станет games/<id>/):
    __init__.py        GAME_INFO и create_widget()
    core/              правила — чистый Python/numpy, без Qt
    ai/                ИИ: поиск, оценка, загрузка моделей
    train/             обучение (python -m game.train ...), журнал, снимки
    ui/                виджеты Qt этой игры
    models/            готовые модели + паспорта *.json
  tests/               pytest; тесты окна только offscreen
  build.py, installer.nsi, docs/, README.md, README.ru.md, CHANGELOG.md, LICENSE
  .gitea/workflows/ci.yml (runs-on: windows), .github/workflows/ci.yml
```

## Вход игры

```python
GAME_INFO = {
    "id": "durak",                    # латиница, уникально
    "title": {"ru": "Дурак", "en": "Durak"},
    "summary": {"ru": "...", "en": "..."},   # одна строка для списка игр
    "preview": "docs/preview.png",    # 16:9, для списка игр
    "version": "1.0.0",
}

def create_widget(ctx) -> "QWidget":
    """ctx: aikit.Context — тема, язык, настройки игры, статистика, звук, путь к данным."""
```

- Игра не создаёт своё главное окно. Отдельный запуск идёт через `aikit.run_standalone(GAME_INFO, create_widget)`, оболочка вставляет тот же виджет.
- Игра не пишет файлы куда попало. Только в `ctx.data_dir`, в `%APPDATA%\<программа>\<id>`.
- Смену темы и языка игра подхватывает на лету, по сигналу `ctx.changed`.
- При закрытии игра останавливает свои потоки (поиск, ИИ, анимации) за 2 секунды. Тест обязателен.
  Оболочка зовёт для этого `shutdown()` виджета; `False` в ответ значит «потоки не остановились».
- **Рекомендуется, не обязательно:** `pause()` и `resume()` у виджета. Оболочка зовёт их, когда
  вкладку игры скрыли (перешли на другую, свернули окно) и показали снова. Нет их - оболочка
  сама останавливает QTimer и анимации виджета, но потоки ИИ и `QTimer.singleShot` так не
  остановить: игре с ИИ против ИИ или с ходом по таймеру лучше иметь свои.
- Необязательный ключ `GAME_INFO["langs"]`, например `["ru"]`: игра пока не переведена, в списке
  игр об этом подпись. Без ключа считается, что игра говорит на обоих языках.
- Проверить папку игры: `python tools/contract_check.py ПАПКА --run` в PythonAiGames.

## aikit — общий набор

- темы Paint (светлая и тёмная), палитры, шрифты;
- настройки (JSON), window-state;
- статистика: партии, победы, рекорды по уровням;
- звук: короткие звуки, громкость, выключатель;
- виджет «Мысли ИИ»: тепловая карта по клеткам, оценки ходов, стрелки направлений;
- `aikit/nn`: слои numpy (dense, conv), Adam, сохранение в npz, проверка градиентов. Источник — `nn/` из TicTacToeAi;
- журнал обучения: прогресс в файл, снимки, продолжение с места, ограничение потоков;
- турнир: N партий с зерном и таблица результатов для паспорта модели;
- подписи с переносом и выпадающие списки — по памяти (qt-wrapped-label-height, qt-combo-dropdown).

Первая игра, у которой появится `aikit`, берёт его из TicTacToeAi и ChessCheckersAi. Следующие копируют у предыдущей и несут улучшения обратно. В каждой копии `aikit/VERSION`, при переносе остаётся одна версия.

## Общие правила для всех игр

- PySide6, numpy, **без pygame**. PyTorch — только по решению Алексея.
- **ИИ честный:** видит только то, что видит игрок, и не быстрее заданной реакции, где это важно. Каждый случай закрыт законом-тестом.
- **Уровни:** новичок, средний и сильный, плюс режим «ИИ против ИИ» или «ИИ играет сам».
- **Паспорт модели** с цифрами против простых ботов. Тесты пересчитывают малую выборку с теми же зёрнами.
- **«Мысли ИИ»** — выключатель в каждой игре.
- **Тесты:**
  - сначала красный тест, потом мутационная проверка;
  - окна только offscreen, без видимых окон и захвата мыши;
  - ожидания с тайм-аутом.
- **Обучение** запускается только по команде, с ограничением потоков. Время обучения записывается в паспорт.
- **README** на английском и русском, CHANGELOG, заметки к выпуску.
- **Личное не публиковать:** почту, полное имя, адрес Gitea, личные пути к папкам на диске. Удалять только в Корзину.
- **GitHub** (уточнение Алексея 03.10.2026): у **каждой** игры будет свой репозиторий на GitHub. Их создаёт Алексей, адрес вписывается в spec игры. Выкладка идёт как обычно: сначала Gitea, потом GitHub через `tools/publish_github.sh`. Кроме того, все игры вместе выходят в AiGameRoom.
