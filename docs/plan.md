# PythonAiGames: план работ

Описание - в `spec.md`, контракт игры - в `contract.md`, очередь - в `queue.md`.

## Этап А. До оболочки (идёт внутри игр волны 2)

1. **Первый `aikit`.** Его собирает первый агент волны 2 из TicTacToeAi, ChessCheckersAi и Calibrate3dPrinter (темы, window-state). Сразу копия сюда, в `PythonAiGames/aikit`, с тестами.

## Этап Б. Оболочка (волна 3)

2. **Каркас:**
   - `git init`, LICENSE (MIT), README EN/RU;
   - CI для Gitea (`runs-on: windows`);
   - `aikit` с тестами.
3. **Оболочка.**
   - Список игр: превью, название, строка описания, поиск.
   - Открытие игры в той же оболочке и возврат в список.
   - Общие настройки: тема, язык, звук.
   - Общая статистика.
   - Window-state.
4. **Загрузка игр.** Игры находятся в `games/*/__init__.py` по `GAME_INFO`. Сломанная игра не роняет оболочку: в списке она показывается «не загрузилась» с причиной.
5. **Перенос готовых игр волны 2.**
   - Тесты каждой игры проходят внутри оболочки.
   - Закон: после выхода из игры её потоки остановлены, а память вернулась к уровню до запуска с допуском.
6. **Сборка:**
   - один установщик и portable;
   - замер размера;
   - крупные модели - файлами выпуска со скачиванием и проверкой хэша.

## Этап В. Игры приходят по мере готовности (волны 3-6)

7. Каждая новая игра после своего 1.0 переносится сюда: копия `game/` в `games/<id>/`, тесты, снимок для списка.
