# Как игры попадают в оболочку

## Решение: копии в `games/`, а не пути в файле-списке

Было два пути: файл со списком путей к папкам игр или копии игр в `games/<id>/`. Выбраны
копии, как и задумано в `spec.md` («перенос - копирование `games/<id>`»). Причины:

- у каждой игры свой пакет `game`. Два пакета с одним именем в одной программе не уживаются:
  второй `import game` вернул бы первую игру;
- одна сборка (установщик, portable) должна нести игры внутри себя, а не ссылаться на чужие папки;
- копия фиксирует версию игры: в `games/<id>/VENDOR.json` записаны папка-источник, коммит и
  версия её `aikit`. Пока игра растёт у себя, оболочка не ломается от её незаконченных правок.

## Как сделать копию

```
python tools/vendor_game.py durak        # одна игра из соседней папки
python tools/vendor_game.py --all        # все из games/vendor.json
```

- Папка игры не меняется. Копируется `game/` и превью из `GAME_INFO["preview"]`.
- Импорты переписываются по дереву разбора: `from game.ai import x` -> `from games.durak.ai import x`,
  в том числе внутри функций. Строки и комментарии не трогаются. То, что нельзя переписать без
  смены смысла (`import game.ai`, `import os, paths`), останавливает копию с объяснением.
- Прежняя копия уходит в Корзину.
- Новая игра: строка в `games/vendor.json`, затем `vendor_game.py <id>`, затем тесты. Тест
  `test_games.py` сам берёт все игры из `games/`.

Раскладки в `vendor.json`:

| Раскладка | Для чего | Что копируется |
|---|---|---|
| `contract` | игры по `contract.md` (Дурак и все новые) | `game/` -> `games/<id>/` |
| `legacy` | игры до контракта (TicTacToeAi) | папки и модули из `map`, файлы из `copy`; файлы из `keep` (переходник) остаются от прежней копии |

## Что игра получает от оболочки

`create_widget(ctx)` - у каждой игры свой `aikit.Context`:

- `ctx.data_dir` - `%APPDATA%\AiGameRoom\<id>`; игра пишет только туда;
- `ctx.theme`, `ctx.lang`, сигнал `ctx.changed` ('theme' / 'lang');
- `ctx.stats`, `ctx.sound` (громкость общая), `ctx.file(...)`;
- `ctx.set_theme/set_lang/set_volume` из настроек самой игры - оболочка разносит смену по всем
  открытым играм и себе. Общие настройки - в `%APPDATA%\AiGameRoom\host.json`.

## Жизнь вкладки

| Событие | Что делает оболочка |
|---|---|
| Открыть | `create_widget(ctx)`; ошибка - подпись на карточке игры, оболочка живёт |
| Скрыть вкладку, свернуть окно | `pause()` игры; нет его - стоп таймеров и анимаций виджета, а таймер, заведённый игрой заново, глотает фильтр событий |
| Показать снова | `resume()`; нет его - таймеры и анимации снова идут |
| Закрыть вкладку | `shutdown()` (до 2 с, иначе запись в журнал проблем), стоп таймеров, удаление виджета и ctx |
| Закрыть окно | то же для всех вкладок, место окна - в `window.json` |

Тесты `tests/test_games.py` проверяют это на каждой игре из `games/`: после закрытия
виджетов столько же, сколько до открытия, потоки остановлены, за 4 круга открыть-закрыть
память не растёт больше чем на 1,5 МБ, игра не пишет в свою папку.

## Проверка контракта

```
python tools/contract_check.py ..\DurakAiGame --run    # папка игры
python tools/contract_check.py --games --run           # все копии
```

Каждая находка - уровень, правило и понятный текст, например
`ОШИБКА [code.pygame] ui/view.py:1: import pygame - только PySide6, без pygame`.
Код возврата 1 при хотя бы одной ошибке.
