# PythonAiGames: ИИ-Игротека на Python

Одна программа, внутри которой собраны все игры Алексея с собственным ИИ. Слева список игр с превью, справа выбранная игра. Общее у всех игр: меню, настройки, темы, статистика, язык, окно «Мысли ИИ», сборка и выпуск.

Решение Алексея от 03.10.2026:
- сначала каждая игра делается в своей папке;
- потом всё переносится сюда, в одну программу;
- на GitHub выкладывается один репозиторий вместо отдельных;
- старые отдельные репозитории SnakeAi, AiCar, TicTacToeAi и AiBoy удаляются.

Работа не огромная: меню, настройки и окно у игр общие. Каждая следующая игра берёт готовое у предыдущих.

План работ — в `plan.md`, обязательные правила для каждой игры — в `contract.md`, очередь агентов — в `queue.md`.

## 2. Как будет устроена единая программа

```
PythonAiGames/
  main.py                 запуск, --selftest, --game <id>
  aikit/                  общее: темы, настройки, window-state, статистика, звук,
                          виджет «Мысли ИИ», журнал обучения, nn/ на numpy, paths
  shell/                  окно-оболочка: список игр, превью, поиск, настройки
  games/<id>/             каждая игра: core/ (правила), ai/, train/, ui/, models/, tests/
  tools/                  build.py, publish_github.sh, снимки для README
  docs/
```

- **Игры не зависят друг от друга**, только от `aikit`.
- Игра открывается в той же оболочке. Закрыл — вернулся в список, игра выгружается и освобождает память.
- **Модели** лежат в `games/<id>/models/`. Если всё вместе слишком большое, крупные модели идут файлами выпуска и скачиваются при первом запуске игры, с проверкой хэша.
- **Сборка одна:** установщик NSIS и portable. Размер следим: общий Python и Qt на все игры дают гораздо меньше, чем 16 отдельных программ.
- **PyTorch** не нужен играм. Если какой-то игре он всё же понадобится, это решается отдельно с Алексеем: torch тянет больше 1 ГБ.
- **Статистика** общая: сколько партий в каждой игре, лучшие результаты, против какого уровня ИИ.
- **Язык:** RU/EN. **Темы:** темы Paint. **Без pygame.**

## 3. Переход: отдельные папки, потом одна программа

1. **Сейчас.** Каждая новая игра делается в своей папке по `contract.md`. Тогда перенос — это копирование `games/<id>` плюс удаление своей копии `aikit`.
2. **Старые игры** (TicTacToe, Snake, AiCar, AiBoy) переводятся на контракт при переносе.
3. **Оболочка.** Её делают, когда готовы 3–4 новые игры, чтобы проверить контракт на живых играх. Остальные игры потом приходят уже в неё.
4. **Отдельные репозитории** остаются и на Gitea, и на GitHub. Уточнение Алексея 03.10.2026: «на гитхабе создам для каждого репозитории… туда все выложим, особенно то, что уже готово». Каждая игра выходит отдельно и ещё в составе `AiGameRoom`.

Ничего не удалять без отдельного «да» Алексея; удаление необратимо, мягкий вариант — архивировать со ссылкой.
